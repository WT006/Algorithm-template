# Algorithm Template · 多语言算法模板

一份按知识点整理的 C++、Java、Python、Go、TypeScript、Rust 算法模板与学习笔记，用来记录常见算法的实现，方便刷题时查阅、复习与改写。

每种语言各有一份 Markdown 文档，涵盖基础算法、数据结构、搜索与图论、数学、贪心、动态规划、高精度运算以及莫队算法。C++ 保留原始学习笔记与题目示例；其余五个版本按相同知识点提供函数与数据结构，合并重复示例并说明适用条件。

## 语言版本

| 语言       | 文件                                   | 使用方式                                                     |
| ---------- | -------------------------------------- | ------------------------------------------------------------ |
| C++        | [CppTem.md](./CppTem.md)               | 按小节选用原始模板，补齐所需头文件、声明和输入输出           |
| Java       | [JavaTem.md](./JavaTem.md)             | 49 个算法小节；把选用的静态方法、静态类放进 `Main`，导入 `java.util.*`、`java.math.BigInteger` |
| Python     | [PythonTem.md](./PythonTem.md)         | 49 个算法小节；按需复制函数、类与标准库导入                  |
| Go         | [GoTem.md](./GoTem.md)                 | 49 个算法小节；函数、类型放在 `package main` 中，按需导入标准库 |
| TypeScript | [TypeScriptTem.md](./TypeScriptTem.md) | 49 个算法小节；严格类型，普通算法使用 `number`，精确整数运算使用 `bigint` |
| Rust       | [RustTem.md](./RustTem.md)             | 49 个算法小节；标准库实现，使用索引、切片与 `Option`，无需第三方 crate |

Java 使用 Java 8 及以上语法，Python 使用 Python 3.8 及以上语法，Go 使用 Go 1.21 及以上，TypeScript 目标为 ES2020 及以上，Rust 使用 2021 edition。五个新版本均默认零基下标，树状数组使用一基下标；区间约定与前置依赖见各节说明。

TypeScript 的 `number` 运算要求所有中间整数也在安全整数范围内；模运算和精确大整数使用 `bigint`。Go 使用 `math/big`，Rust 的精确组合数及大整数运算使用本文的十进制数位实现。

## 参与完善

欢迎通过 Issue 或 Pull Request 反馈错误、补充说明和完善模板。

报告问题时，请尽量提供：

- 对应的章节、算法名称和出错代码。
- 能复现问题的输入、预期输出与实际输出，或完整的编译错误信息。
- 编译器及版本；如果已有修复思路，也欢迎一并说明。

新增或修改模板时，建议说明适用条件、时间与空间复杂度，并提供最小示例或边界测试。命名风格和缩进应尽量与相邻内容保持一致，便于读者对照学习。
